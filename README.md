# Alfa-Tehnostrelka-2026

Автоматизированный инструмент разработки программного обеспечения, построенный на мультиагентной архитектуре с использованием искусственного интеллекта. Данный проект позволяет генерировать полный цикл разработки: от анализа требований (Use Cases) до написания кода, тестов и документации.

## Возможности

- **Автоматическая генерация**: Создание ПО на основе текстового описания.
- **Мультиагентная система**: Независимые агенты (Директор, Аналитики, Разработчики, Тестировщики) взаимодействуют для достижения общей цели.
- **Файловая система**: Полная интеграция с файловой системой для чтения, записи, создания папок и выполнения команд.
- **Интеграция OpenRouter**: Поддержка множества моделей через API OpenRouter.

## Технологии

- **Python**
- **LangChain**: Для управления агентами и инструментами.
- **LangChain-OpenAI**: Для работы с API моделей.
- **Uv**: Быстрый менеджер пакетов Python.

## Установка

### Требования:

- Python версии 3.10 или выше.
- Установленный менеджер пакетов Uv.

### Установка зависимостей:
Инициализируйте окружение и установите библиотеки, указанные в pyproject.toml:

```bash
uv sync
```

### Настройка .env:
Создайте файл `.env` в корневой директории проекта и добавьте туда ваш ключ OpenRouter и базовую модель:

```
API_KEY=your_openrouter_api_key_here
DEFAULT_MODEL=your_model
```

(Опционально: можно задать модель и другие параметры в коде или через переменные окружения).

```
<type>_MODEL=your_model
```

## Использование

### Создание папки с промптами (System Messages)
Проект автоматически загружает инструкции (System Messages) из папки `prompts` (или создайте её и поместите туда текстовые файлы с описанием ролей агентов).

Запустите скрипт через менеджер uv:

```bash
uv run --env-file ".env" .\main.py
```

**Результаты**: После успешного выполнения, код, файлы, тесты и документация будут сохранены в директории `output`.

## Работа агентов

Проект использует архитектуру **"Директор + Агенты-специалисты"**:

### 🎯 Director (Директор/Оркестратор)
- **Файл**: `director.md`
- **Ответственность**: Планирует задачи, координирует работу всех агентов, контролирует процесс выполнения

### 📊 Агенты
- **Use Cases Agent** (`use_cases.md`) - Генерирует сценарии использования системы
- **Non-Functional Requirements Agent** (`non_func_req.md`) - Определяет нефункциональные требования (производительность, безопасность и т.д.)
- **Functional Requirements Agent** (`func_req.md`) - Создает функциональные требования
- **Application Planning Agent** (`gen_app_plan.md`) - Планирует архитектуру и структуру приложения
- **Code Generation Agent** (`code_gen.md`) - Пишет исходный код приложения
- **Tests Agent** (`tests.md`) - Создает тесты и тестовые сценарии
- **Tester Agent** (`tester.md`) -Тестирует программу
- **Documentation Agent** (`docs.md`) - Генерирует README, техническую документацию и комментарии
